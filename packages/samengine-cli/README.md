# Samengine CLI

This package contains 1 CLI Tools which can used with samengine
and although other projects

Run them by typing this:

```sh
npx samengine-cli-buildinfos --help
```

## INFO

This package uses other Version numbers than **samengine** and
**samengine-build** because it does not depend on them!

Linksaver moved, because i decied that GO would be a better language
for CLI Tools

And Probably more Tools for samengine will not be written in JS, but
they will be mentioned in the README File of the samengine Framework!
